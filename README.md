# Zhuoran Li — Personal Homepage

A dependency-free academic homepage for GitHub Pages. The site is built with semantic HTML, CSS, and a small amount of JavaScript; no build step is required.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Enable GitHub Pages from the repository root on the `main` branch. No external deployment is performed by this workspace.
